---
title: Text formatting and native HTML
---

Ordinary Markdown supports **bold**, *italic*, ***both***, ~~strikethrough~~,
and compact `inline code`.

Native HTML works too: press <kbd>Enter</kbd>, read some <mark>highlighted text</mark>,
or use a harmless <abbr title="HyperText Markup Language">HTML</abbr> abbreviation.

> Formatting remains available inside **blockquotes** with *emphasis* and `code`.
