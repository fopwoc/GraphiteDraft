---
title: Highlighted, copyable code blocks
---

Click a block or focus it and press <kbd>Enter</kbd> to copy its contents.

## Multiple languages

```ts
const pages = await build("./notes");
console.log(`Built ${pages.length} pages`);
```

```kotlin
fun main() {
    println("Markdown becomes a website")
}
```

An unknown language still renders as a readable code block:

```text
plain text remains plain text
```
