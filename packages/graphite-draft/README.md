# Graphite Draft

Graphite Draft turns a directory of Markdown and MDX into a static website.

```sh
npm install --global graphite-draft
graphite-draft check ./notes
graphite-draft build ./notes ./dist
```

See the [project README](https://github.com/fopwoc/GraphiteDraft#readme) for the
GitHub Action, Docker image, page-authoring features, and full CLI usage.
